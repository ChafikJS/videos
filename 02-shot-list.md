**How to use it**

- Every image and video prompt is self-contained: character, location and style descriptions are already written in, so paste them as they are. Generate the image first, then use it as the start frame for the video prompt (image-to-video) to keep characters and sets consistent.
- Most video generators produce 5-10 second clips. For a longer scene, generate two to four clips from the same start frame (vary only the camera movement) and add inserts of the objects named under *Visual*. Aim for a cut every 6-10 seconds.
- AI generators render text badly. Add all on-screen text in the edit: CCTV timestamps, room numbers, scanner and computer screens, the plaque engraving, the title card.
- Timestamps assume the narration pace in the script. After recording the voice-over, slide each scene to the real audio.
